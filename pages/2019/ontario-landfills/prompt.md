Converted from the 2019 browserify/deck.gl original in public/2019/ontario-landfills.
Notes: the deck.gl GeoJsonLayer scene (pitch-50 camera over toronto, 4500m extruded landfill pillars, 116m lake, flat 0.1-opacity city fills, highway lines, landfill hover tooltip, scroll-zoom off, zoom locked 6.6–9) was rebuilt with maplibre-gl fill-extrusion/fill/line layers on a blank #fbfbfb style. Approximations: deck's default lighting was baked in by darkening fill colors ~0.69x (cities' 0.1 opacity became 0.35 to match deck's gamma-corrected alpha); map height is 80vh (the original canvas filled the viewport); highway width is a ~2.3px→9px zoom ramp (deck used max(2px, 1000m)) and sits at ground level, so the lake top can cover it at shoreline crossings. The 'By capacity:' somehow v0.3.3 svg chart was reimplemented as inline svg with identical geometry (100x54 widescreen viewBox, truncating scales, 4px non-scaling-stroke blue lines, 1.5px grey end-labels, 2px/4px responsive title); the chart gets 13% right padding so end labels stay inside the card. The one-line gray subtitle was added for the standard header shell (the original had only a title).
